# Track A · 기하 추정을 보조하는 지도학습 PoC

이 실험은 영상 후보를 처리하는 기존 기하 추정기의 세 결정을 학습으로 보조한다. 모델은 상자의 자세를 직접 회귀하지 않는다. 영상 특징과 카메라 보정에서 얻은 추정 정보로 물리 에지 후보를 점수화하고, 가설의 우선순위를 정하고, 고정 대응을 사용한 강체 적합에서 에지 잔차의 가중치를 정한다. 추정 경로는 인공 마커와 정답 물리 ID에 의존하지 않는다.

## 재현

저장소 루트에서 실행한다. 수치 라이브러리 한 스레드와 3 GiB 프로세스 커밋 상한에서 NumPy CPU로 실행했다.

```powershell
python -B -m evaluation.resource_limits --threads 1 --memory-gib 3 learning.track_a
python -B -m unittest learning.test_track_a -v
```

[공통 D0 생성기](../../learning/datasets.py)는 Layout A, 알려진 상자 치수, 세션 단위 train/dev/lockbox 분리를 사용한다. Track A는 같은 원시 검출을 재생한다. Open-loop에서는 공개 D0 패킷과 같은 Phase II reliable의 직전 유효 추정값을 공통 prior로 사용한다. Closed-loop에서는 각 방법이 같은 첫 coarse prior에서 시작해 자기 직전 유효 자세를 이어받는다. 시작 prior는 합성 정답에 잡음을 준 값이다. 이후 정답은 훈련 손실과 평가에만 쓰이며 oracle 경로만 선택 때 참조한다. 정규화 평균과 분산은 train에서 구하고, 대응 점수 문턱과 closed-loop에 올릴 학습 구조는 dev로 정한다. 기본 12프레임 시퀀스는 짧은 구간의 비교이며 장시간 복구 성공을 검증하는 설정은 아니다.

## 후보 점수, 에지 대응과 자세 적합

에지 후보는 보이는 모델 에지와 관측 선분의 조합 중 수직거리 14 px 이하, 각도 차 34° 이하, 유한 겹침 비율 25% 및 겹침 길이 5 px 이상인 쌍으로 제한한다. 입력은 수직 잔차, 각도, 유한 겹침, 길이·방향 위치, 연결 코너의 지지, 모델 깊이를 포함한다. 학습 목표는 후보의 모델 ID와 검출의 물리 ID가 일치하는지 여부다. 클래스 빈도를 반영한 이진 손실로 logistic과 은닉층 16개인 tanh MLP를 각각 학습한다. 최적화는 NumPy Adam 450회이며, 클래스 균형 손실에서 나온 점수는 보정된 확률로 해석하지 않는다.

Dev에서 정한 점수 미만의 조합은 금지한다. 남은 후보는 미할당 더미를 포함한 Hungarian으로 주 대응을 정하고, 다른 검출과 과도하게 겹치지 않는 조각을 같은 모델 에지에 추가한다. 카메라마다 같은 물리 에지의 조각을 한 지지선으로 합친 뒤 코너와 함께 기존 강건 자세 추정기에 넣는다. 좁은 Phase IV 기하 대응과, 학습기에 동일한 넓은 후보 공간과 코너 대응을 제공하는 기하 비용 대조군을 각각 포함했다. `oracle_edges`는 에지 대응에만 합성 물리 ID를 사용한다. Oracle의 코너는 계속 추정하며 마지막 pose 유효성 검사를 적용한다.

원시 D0 검출은 물리 에지당 보이는 구간 하나를 주로 반환한다. `open_fragment`은 lockbox의 매 4번째 프레임에서 34 px 이상인 선분을 서로 떨어진 두 조각으로 바꾼 추가 검사다. 진짜 에지와 클러터에 동일한 변환을 적용하며 이 검사를 모델 선택이나 학습에 쓰지 않는다.

## 신뢰도 가중과 가설 순위

가중치 비교에는 두 방법 모두 동일한 Phase IV 기하 대응, 에지 조각 지지선과 3 px Huber 적합을 사용한다. `learned_huber`는 에지의 대응 점수 평균을 최소 0.08로 자르고 그 에지의 두 잔차에 같은 가중치를 곱한다. 코너의 가중치는 1이다. 이는 물리 ID 분류 점수를 오대응 억제에 재사용하는 실험이다. 별도의 최종 자세 손실로 추정된 관측 공분산을 학습한 결과와 구분한다.

순위 모델은 동일한 Phase IV 세 시점 후보를 비교한다. 입력에는 내부 시점 잔차, 유효 지지와 관측 수, 최소 고윳값과 조건수, 제외 시점 잔차 및 가용성, 대응 안정성, prior와의 거리가 들어간다. 유효 플래그와 랭크 6을 만족하는 가설만 선택 대상이다. 훈련에서는 같은 프레임 가설 쌍에서 $e=t_{mm}/20+r_{deg}/8$가 작은 가설을 선호하도록 pairwise logistic loss를 최소화한다. 선형 및 16-unit MLP를 최소 내부 RMS, 교차시점 휴리스틱, 같은 후보 집합의 최소 $e$를 선택하는 oracle과 비교했다. Oracle이 별도의 좋은 자세를 생성하는 것은 아니며, 유효 후보가 없는 프레임은 oracle도 출력하지 않는다. Closed-loop oracle의 자체 prior는 이전 oracle 선택에서 이어지므로 진단용 참조치로 해석한다.

## 지표 및 파일

- 자세 RMSE와 P95는 유지 자세를 포함한다. 실패는 프레임 무효 또는 20 mm나 8° 초과다. False-valid 분모는 유효로 표시된 프레임이다.
- 에지 precision의 분모는 유효 자세에서 내보낸 에지 조각 대응 수다. Recall의 분모는 시뮬레이터가 생성한 참 에지 조각 수다. 미검출 자체에는 라벨이 없으며 실패 프레임에서 내보낸 대응은 0건으로 계산한다.
- 시점 쌍 정확도는 같은 모델 ID를 주장한 카메라 쌍 중 양쪽에 해당 ID의 참 물리 대응이 적어도 하나씩 있는 비율이다. 동일 뷰의 조각은 시점 쌍 수를 늘리지 않는다. 가림 보완은 지정 뷰에서 기하적으로 잃은 물리 ID 중 다른 뷰가 바르게 대응한 비율이다.
- 순위 top-1과 regret는 방법이 출력을 선택한 프레임만 분모로 사용한다. 가설 출력 수와 oracle 가용 프레임 수를 함께 해석한다. Regret는 선택한 가설의 $e$와 해당 프레임 최선 후보의 $e$ 차이다.
- Open-loop 순위 시간은 기하 후보 생성이 끝난 상태의 선택 시간이다. Closed-loop 순위 시간에는 가설 생성도 포함한다. Open-loop 에지 모델은 공유 후보 특징 생성 후의 시간이며, 폐루프 에지·가중치 시간에는 대응 특징 생성과 자세 적합을 포함한다. 타이밍은 검출 입력 이후 CPU 단계의 측정이다.

실행 결과는 [프레임별 기록](track_a_results/frames.csv), [방법·조건별 집계](track_a_results/summary.csv), [고정 프로토콜과 dev 선택](track_a_results/protocol.json)에서 확인할 수 있다. [모델 학습](../../learning/track_a_models.py)과 [단계 통합](../../learning/track_a_geometry.py)은 기본 추정기에 변경을 가하지 않는다.

## 측정 결과

Train에서 에지 후보 4,026쌍 중 2,392쌍이 물리 ID 정쌍이었고 순위 비교 쌍은 438개였다. Dev는 에지 MLP와 점수 문턱 0.35, 순위 선형 모델을 선택했다. Lockbox는 궤적 16개, 192프레임으로 구성했다. 밑의 자세 오차는 유효·무효 프레임을 함께 집계하며 각 행의 자세는 자체 이력에서 이어진다.

| Closed-loop 에지 대응 | Precision | Recall | F1 | 위치 / 회전 RMSE | 실패율 |
|---|---:|---:|---:|---:|---:|
| 기존 좁은 기하 gate | 84.95% | 24.08% | 37.53% | 63.78 mm / 21.23° | 59.90% |
| 넓은 기하 비용 | 80.69% | 44.74% | 57.56% | 81.17 mm / 16.95° | 38.54% |
| 학습 MLP | 90.18% | 46.54% | 61.39% | 645.79 mm / 14.45° | 32.29% |

공통 prior를 쓴 기본 검출의 open-loop에서도 MLP의 F1은 49.96%로 넓은 기하의 48.89%보다 소폭 높았다. 반면 분절을 추가한 48프레임에서는 MLP F1이 8.80%였고 넓은 기하는 40.28%였다. Pose가 유효하다고 표시한 출력의 신뢰도도 따로 봐야 한다. Closed-loop MLP가 유효라고 내보낸 178개 중 26.97%가 오차 한계를 넘었다. Open-loop 에지 oracle은 에지 ID를 고정하고 나머지 추정을 유지했을 때 3.62 mm / 1.49°와 실패율 1.56%를 기록했다.

가설 순위 선형 모델의 open-loop top-1은 76.83%이고 최소 내부 RMS는 67.07%였다. 두 방법 모두 192개 중 82개에서만 유효 후보를 선택했고 전체 실패율이 58.85%였다. 선택 가능한 가설이 없는 프레임은 ranker로 복구할 수 없다. 공통 후보 oracle도 동일한 82개만 선택했다. Closed-loop 선형 모델과 최소 내부 RMS는 모두 89개를 선택했고, 위치 RMSE는 각각 59.52 mm와 59.57 mm, 실패율은 모두 55.73%였다. 순위 일치율이 개선되어도 자세 추적이 개선된다는 근거는 약하다.

Closed-loop Huber에 학습 가중치를 더하면 위치 RMSE가 63.78 mm에서 62.53 mm로, 실패율이 59.90%에서 56.77%로 변했다. 회전 RMSE는 21.23°에서 22.81°로 늘었다. 해당 피팅 단계의 p50/p95는 각각 9.59/14.36 ms와 15.08/21.13 ms였다. 이 설정에서 개선 방향이 지표마다 달랐다.

## False-valid 재현과 가림 보완 검사

`D0-lockbox-76405`의 프레임 4에서는 보정 결함이 있는 대각 시점만 사후 지원 조건에 맞는 상태로 22.17 mm의 결과가 수락됐다. 다음 프레임에는 코너가 한 개도 대응되지 않았다. 정면의 두 선분과 대각선의 한 선분에서 물리 ID 정쌍은 정면 한 쌍뿐이었다. 남은 두 쌍은 클러터와 잘못된 ID였다. 초기 Jacobian의 조건수 145.95는 기존 적합의 유효 문턱에 들어왔고, 여섯 스칼라 선 잔차의 Huber 목적은 168.23에서 5.07로 감소했다. 이런 소수의 무한 지지선에는 1.30 px RMS로도 잘못된 3D 배치를 맞출 수 있었다.

출력은 이전보다 3.296 m 움직여 물리 오차가 3.347 m가 됐다. 출력 꼭짓점은 네 카메라 앞에 있었으나 센서 안에 남은 시점은 정면뿐이었다. 정면의 참 대응도 출력 모델 투영 길이 39.4 px, 검출 길이 152.6 px였고 사후 유한 구간 검사를 통과하지 못했다. 대각 오대응의 모델 에지는 출력 자세에서 센서에 보이지 않았다. 최종 정규화 최소 고윳값은 0.000215, 조건수는 511,438이었고 대응을 넣은 시점을 포함해 지원 문턱을 만족한 시점이 없었다. 이 PoC가 사용한 기존 적합의 초기 랭크 판정에 최종 지지도, 센서 경계, 자세 이동량 검사까지 포함되지는 않는다. 다음 프레임부터 대응이 끊겨 자세를 유지했고, 마지막 7프레임이 전체 MLP 위치 제곱 오차의 99.62%를 차지했다. 결과는 그대로 보존했다. [사후 검사 원시 추적](track_a_results/outlier_trace.json)

기본 D0의 직사각형 가림은 에지 일부를 줄였지만 해당 임계값에서 완전히 잃은 에지 사건을 한 건도 만들지 않았다. 따라서 기본 D0 가림 보완율 칸은 공란이다. [별도의 구형 가림 검사](../../learning/occlusion_sanity.py)에서 정면, 측면, 상단을 각각 가린 72프레임에 동결된 모델과 문턱 0.35를 적용했다. 대응 단계와 자체 이력은 기본 폐루프와 같다.

| 가려진 시점 | 좁은 기하 | 넓은 기하 | 학습 MLP |
|---|---:|---:|---:|
| 정면 | 47 / 127 | 81 / 127 | 66 / 127 |
| 측면 | 70 / 186 | 103 / 186 | 85 / 186 |
| 상단 | 20 / 49 | 32 / 49 | 24 / 49 |

각 분자는 가려진 시점의 물리 에지 ID를 다른 시점이 바르게 대응한 횟수다. 넓은 기하가 세 방향 모두에서 가장 많은 에지를 보완했다. 좁은 기하보다 많이 보완했다는 결과만으로 학습 효과를 분리할 수 없다. 이 검사는 두 궤적과 구형 손으로 제한된다. [방향별 결과](track_a_results/axis_fixture_summary.csv) · [프레임별 자료](track_a_results/axis_fixture_frames.csv)

```powershell
python -B -m evaluation.resource_limits --threads 1 --memory-gib 3 learning.track_a --prepare-only
python -B -m evaluation.resource_limits --threads 1 --memory-gib 3 learning.track_a_diagnose --axis-fixture
```

`--prepare-only`는 lockbox를 읽지 않고 train에서 동일 가중치를 재생성한다. [네 체크포인트](track_a_results/models.npz)와 [배열 해시 및 CPU 최적화 시간](track_a_results/training.json)을 함께 저장했다. 입력 특징 생성은 17.17 s, 에지 MLP의 가중치 최적화는 0.223 s, 순위 선형 모델의 최적화는 0.116 s였다. 목표는 학습 보조의 경계와 실패 조건을 파악하는 것이며 이번 결과로 기본 기하 정책을 교체할 근거는 확보하지 못했다.
