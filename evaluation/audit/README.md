# Phase I 독립 검증

프로젝트 루트에서 `python evaluation/audit/verify_phase1.py`를 실행한다. 2개 배치의 원 실험과 별도로, 반대쪽 배치의 네 카메라 × 세 자세 × 여덟 꼭짓점에서 OpenCV projectPoints로 계산한 좌표와 직접 구현을 대조했다. 최대 차이는 2.62×10⁻¹² px였다. 좌측 SE(3) 업데이트의 6개 열을 중앙 차분(±10⁻⁶)한 최대 차이는 7.02×10⁻⁸이었다.

원본 run_trial에 동일 픽셀을 공급하고 평가용 물리 ID만 순환 치환했다. 네 프레임의 Estimated 24행에서 위치·회전 오차, 성공 플래그와 대응 개수가 모두 동일했고 Oracle 24행에서는 결과가 바뀌었다. estimated_associations는 prior, camera, detections만 받고, Oracle에만 labels가 전달된다. GT는 관측·가시성 합성, 검출 오차 집계와 평가에 쓰인다. initial_pose는 상수이며 trajectory 호출을 금지한 상태에서도 실행된다. 단, 그 상수가 유일한 궤적의 첫 자세에 가깝게 설계돼 있으므로 전역 초기화를 검증한 결과로 해석할 수 없다.

### 확인된 약점

- 생성기와 추정기가 같은 투영·가시성·형상 모델을 공유한다. 레이블을 읽지 않아도 정확한 보정, 시간 동기와 치수를 아는 이상 조건에서 유리하다. 점과 선 잡음이 독립적인 반면 실제 교점과 선분은 같은 픽셀에서 파생된다.
- seed 42~44는 같은 궤적의 관측 잡음만 바꾼다. stress의 26~33 프레임은 모든 시점의 참 코너를 제거한다. 이 구간에서 코너+선의 이득에는 생성 조건의 영향이 있다. 손 구 가시성 분석은 별도의 실험이며 Phase I 자세 추정기에 손 영상이 입력되지는 않는다.
- 원본 solved는 시작점 Jacobian의 랭크 검사를 통과하면 참이다. 수렴, 응답 품질, 후속 오차 임계값 통과를 뜻하지 않는다. 동일 물체가 보이지 않아도 주변 clutter로 랭크를 충족할 수 있다. 실험 실패율에는 무효 자세를 보유하는 프레임도 포함된다.
- 생성기는 후보가 전혀 보이지 않는 카메라에서 길이 0인 배열의 임의 원소를 clutter로 선택할 수 있다. 완전 시야 이탈을 시험할 때는 빈 입력을 명시적으로 처리해야 한다. 국소 예측을 그대로 유지하는 동작은 전역 재검출을 제공하지 않는다.
- 독립 검증은 수식과 대표 실행 경로의 검사다. 과거 튜닝 자료의 계보나 실제 장비에서의 통계적 일반화는 소스 분석만으로 확정할 수 없다.
