# 자세 적합 후 물리 에지 ID 검사

실제 꼭짓점 거리 1.126 m에서 A `x+y-z+`, B `x-y+z-`, 상단 `x-y+z+`, 상단 `x-y-z+` 네 배치의 기존 손 가림 실험을 재실행했다. 같은 시드 13·57·92와 각 28프레임, 기존 검출 생성기·결합 추정기·이전 자세 갱신을 그대로 사용했다. 원본 CSV와 336프레임의 자세 오차 및 원래 대응 수를 대조했다. 후검사는 원래 할당을 유지하거나 삭제하며 새 ID를 만들거나 이후 자세에 반영하지 않는다. 정답 ID는 집계에서만 사용했다.

사전에 고정한 기준은 관측 직선에 대한 모델 전체 에지 양 끝점의 법선 거리 RMS ≤2.5 px, 부호 없는 방향 차이 ≤8°, 모델 방향 위에서 관측 구간과 투영 모델 구간의 유한 중첩이 관측 구간의 60% 이상이다. `in_fit_gate`는 해당 영상까지 포함한 기존 자세로 검사한다. `left_camera_out_gate`는 대상 카메라의 이번 프레임 코너·에지를 모두 빼고 나머지 세 카메라의 같은 초기 대응으로 자세를 구한다. 이 경우도 이전 프레임의 공통 추적 자세를 초기값으로 쓴다.

## 결과

카메라 쌍·모델 에지 ID별로 양쪽 검출이 모두 해당 물리 에지일 때 정답이다. 정밀도의 분모는 판정 후 남긴 쌍 주장, 재현율의 분모는 양쪽에서 같은 물리 에지가 실제 검출된 모든 카메라 쌍 기회다. 한 에지는 여러 카메라 쌍에 나타날 수 있다. 복구는 고정 축 카메라에 지정된 손 때문에 가시성을 잃은 에지 중 한 대 이상의 다른 카메라가 올바른 ID를 유지한 횟수로 센다.

원래 오답 쌍 1,936개 중 1,750개에는 적어도 한 쪽에 클러터 후보가 들어 있었다. 한 카메라에서 잘못 지정한 에지가 다른 카메라 여러 대와 쌍을 이루면 같은 오판이 여러 주장에 잡힌다. 자세 적합은 코너·여러 에지의 결합과 강건 손실로 제약된다. 에지 잔차는 관측 직선의 법선 방향만 제약하므로 가까운 직선이나 길이 방향으로 밀린 후보의 낮은 잔차와 올바른 물리 ID가 동시에 성립하는 것은 아니다. 이 결과는 평균 1 mm 미만의 위치 RMSE와 약 68%의 원래 쌍 정밀도가 함께 나올 수 있음을 보여 준다.

후검사는 오답과 함께 일부 정답도 제거했다. 예를 들어 잡음이 있는 짧은 가림 조각을 전체 모델 에지 끝까지 연장해 검사하면 두 끝점의 법선 잔차가 커질 수 있다. 대상 카메라 제외 방식은 해당 프레임 독립 검사를 제공했고, 네 배치에서 적합 포함 검사보다 정밀도가 조금 더 높고 재현율이 낮았다. 이 실험은 합성에서 ID 주장에 대한 정밀도·재현율 절충을 측정한다. 추적 성능 자체에는 후검사를 적용하지 않았다.

```powershell
python -B -m evaluation.resource_limits --threads 1 --memory-gib 3 evaluation.edge_identity.check --output evaluation/edge_identity/replay
python -B -m evaluation.resource_limits --threads 1 --memory-gib 3 evaluation.edge_identity.test_check
```
