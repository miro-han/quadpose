# 물리 에지에 점수를 매기고 기하 추정에 연결하기

넓은 가시 모델 후보 중 검출 선분이 같은 물리 에지인지 logistic과 작은 MLP로 학습했다. 수직 잔차, 각도, 유한 겹침, 선분 길이, 인접 코너와 모델 깊이를 사용한다. 입력에 정답 ID를 주는 Oracle은 별도로 두었다. 미할당 및 분절된 조각을 허용하는 할당을 통과하면 기존 강체 적합이 자세를 계산한다. 같은 후보 공간의 기하 비용과 비교해 후보 게이트 확대의 효과를 확인한다.

같은 Huber 적합에 에지 점수를 곱하는 관측 가중치와, 유효한 기하 후보 간 선호를 학습하는 가설 순위도 별도로 비교했다. 결함 카메라의 합성 태그 대신 검출·잔차·정보량·이전 자세로부터 유도한 추론 가능한 값을 사용한다.
