파일 최종 정리 내역 — 2026-11-24

1. 읽기 시작점은 루트 README.md, 현재 기술 상태는 PROJECT_CONTEXT.txt로 통일했다.
2. NOTION_SUMMARY.txt는 노션에 붙여 넣을 공유용 글이다. 계정에 게시한 것은 아니다.
3. 이전 README와 PROJECT_CONTEXT는 archive/20261124_before_final에 보관했다.
   이전의 학습 모델 미실행 문장과 깨진 한글을 최신 문서에서 수정했다.
4. 원본 제안서·과제 가이드라인·인계문서는 source/에 복사했다. 원본 Downloads는 유지했다.
5. 코드 폴더(camera, segmentation, edges), 외부 소스(third_party), 모델(models),
   실험 결과(outputs)를 분리한 기존 구조를 유지하여 실행 경로 손상을 피했다.
6. 루트의 번호 실행기로 촬영과 물체 추적에 바로 접근한다. 기존 실행기와 바로가기도 유지한다.
7. Setup_Project.cmd는 새 PC용 공통 설치 경로다. Python 3.10 이상·인터넷이 필요하다.
   현재 PC의 기존 환경을 검증했으며, 깨끗한 다른 PC의 설치 완료까지 검증한 것은 아니다.
8. tools/package_project.py로 가벼운 팀원 전달용 ZIP을 만든다.
   코드·문서·원본 과제 자료·모델 출처와 대표 검증 이미지/로그만 포함한다.
   .venv, .camera_env, 캐시, 원본 영상, 전체 outputs, 모델 가중치, 외부 소스는 제외한다.
   공식 소스/라이선스와 모델은 setup_sam2.py가 고정 커밋/해시로 준비한다.
   따라서 ZIP은 오프라인 완성 배포본이 아니며 처음 실행 전 설치가 필요하다.
9. 원본 영상·모델·실험 결과·진행 중 표시 세션은 삭제하지 않았다.
   과거 JSON의 절대 경로는 옛 위치일 수 있으므로 동봉 검증 자료의 경로 안내를 참고한다.
10. 이번 최적화는 파일 구성과 전달 용량에 대한 것이다. SAM 추론 속도 개선을 의미하지 않는다.
