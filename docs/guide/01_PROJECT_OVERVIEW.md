# 현재 진행상황

네 개의 보정된 RGB 카메라가 한 직육면체를 본다. 측정하려는 값은 시간마다 하나인 물체의 위치와 회전(6DoF)이다. 상자에 고정된 8개 꼭짓점과 12개 모서리에 $e_1$부터 $e_{12}$까지 ID를 주면, 서로 다른 면만 보이는 카메라도 같은 물체의 자세를 계산하는 데 사용될 수 있다. 현재 문제는 손·그림자·인쇄 무늬도 영상에서는 강한 선으로 보인다는 것이다.

계산 조건은 상자의 치수가 알려져있고, 기하학으로 코너+선분 대응시킨 뒤 공동으로 SE(3) 최적화를 돌리는 것이다. 이 과정에서 카메라 4개 중 3개를 이용할 수 있는 조합을 뽑고 신뢰도를 탐색하는 것은 아직 실테스트 해봐야 한다. 인공 마커 사용해서 비교하는 부분은 아직 구현되진 않았다. [인계 시점의 상태](../PROJECT_CONTEXT.txt) · [후속 과제와 구조](../../docs/archive/phase2_README.md)

오른쪽 영상에 길이가 비슷한 선이 있다는 사실만으로는 같은 모서리라고 단정할 수 없다. 직전 자세로 그 물리 모서리를 각 영상에 투영하고 보이는 면·위치·방향·구간을 비교한다. 다른 시점이 같은 모델 ID를 지지하면 동일 모서리의 관측을 보완한다. 다른 ID의 모서리들만 남아도 충분한 독립 제약이 있으면 상자 전체 자세를 구할 수 있다.

실제 녹화 UI, 단일 영상의 SAM 마스크와 에지 후보, 실제 프레임에서의 관측 어댑터는 구현되어있다. 합성된 영상의 네 시점에서 대응/공동 자세/가림/오류 조건을 비교했다. 실제 네 시점의 절대 자세 오차는 실측 실물 촬영이 필요하다. [실영상 어댑터](../../perception/observations/README.md) · [실험 결과의 범위](10_EXPERIMENTAL_RESULTS.md)
