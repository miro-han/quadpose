# 독립 시점의 에지로 보정량을 학습할 수 있는가

세 카메라의 기하 자세 $T_g=(R_g,t_g)$에 작은 병진 $\delta t_\theta$만 더한다. 회전은 고정한다. 출력은 좌표축별 $\pm25$ mm로 제한하고, 정규화의 평균과 표준편차는 학습 궤적에서 계산한다. 학습 모델은 24개 은닉 유닛으로 구성했다. 카메라 세 대의 관측량, 이전까지의 자세 변화, 현재 부분집합의 적합 RMS와 병진이 입력이다.

| 학습 신호 | 목표 |
|---|---|
| 합성 지도 | $t_\mathrm{GT}-t_g$의 Huber 손실 |
| Teacher–student | 전체 카메라 기하 적합의 $t_\mathrm{teacher}-t_g$를 학습. 유효 자세, 3대 이상 지지, RMS 4 px 이하일 때 샘플 선택 |
| 기하 자기지도 | 제외 시점의 고정 대응에서 $\rho(r(T_g)+J_t\delta t_\theta)$와 보정량 정규화. 최종 평가에서 실제 비선형 재투영으로 다시 계산 |

제외 카메라의 현재 검출은 student 입력에서 가린다. 다른 세 대로 적합하기 전에 이전 자세에서 계산한 제외 카메라 대응을 고정해 손실에 쓴다. 현재 프레임의 전체 카메라 teacher 자세를 student 입력으로 넣지 않는다. Teacher와 held-out 대응은 모두 기하 추정이므로 틀릴 수 있다. 실물에서 자기지도 신호를 만들 수 있어도 물체 치수만으로 실측 자세 오차를 알 수 없다.

이 PoC는 미분 가능한 **선형화 잔차**를 통과해 보정 모델을 학습한다. 전체 Gauss–Newton 반복을 미분하거나 대응의 이산 선택을 역전파하지 않는다. 비교 대상인 **시간축 실험**은 각 필터가 자신의 이전 출력에서 다시 대응한다. 마지막 자세 유지, 일정 속도 예측, 고정 이득 0.7과 잔차에 따라 학습한 두 계수 이득을 비교한다. [실험 코드](../../../experiments/neural/residual_study.py) · [비교 결과](EXPERIMENTAL_RESULTS.md)

### 실물 적용 전에 준비할 자료

- 동일 시각으로 정렬된 관측 묶음에는 세션·리그·물체 ID, 프레임/시간, 왜곡 보정 계약, 이미지와 검출·마스크의 경로를 연결한다.
- 기준 촬영은 정지, 3축 병진·회전, 복합 운동, 손의 단일·복수 방향 가림, 빠른 이동과 재진입, 조명·배경 변화를 포함한다. 모델 업데이트와 최종 시험은 촬영 세션이 겹치지 않게 한다.
- Pseudo-label에는 teacher 버전, 대응 ID, 카메라 지지 수·잔차, 추적 상태, valid/confidence를 기록한다. 수동 물리 ID와 독립 지그의 실측 자세는 별도 평가 자료로 둔다.
- 관측이 없거나 대칭인 경우, teacher 여럿이 같은 오답에 수렴할 수 있다. 적용 전에는 카메라 외부 오차, 손과 바닥을 포함한 마스크, 보정을 조금 바꿔도 같은 자세를 반복 출력하는 경우를 확인한다.

현재 워크스페이스에서 확인한 최근 두 녹화 세션은 각각 카메라 1대다. 동기 영상으로 묶을 근거가 확보되면 데이터 계약에 맞춰 재생하고 수정 전후의 측정과 실제 물리 에지 ID를 비교한다. [현장 절차](../../guide/15_PHYSICAL_VALIDATION.md)
