## 공통 좌표와 실행 순서

세계는 미터 단위 오른손 **Z-up**이다. +X는 측면 카메라 쪽, +Y는 정면 카메라에서 안쪽, +Z는 위쪽이다. 기존 시뮬레이션의 (x 오른쪽, y 위, z 정면 쪽) 좌표는 새 좌표 (x, −z, y)로 변환한다. 따라서 축 카메라와 같은 쪽 대각은 새 세계에서 (+,−,+)에 있다. 회전행렬 S의 행은 (1,0,0), (0,0,−1), (0,1,0)이고 det S=+1이다. 물체 로컬 축을 유지하면 T_newWorld_object = S₄ T_oldWorld_object, T_camera_newWorld = T_camera_oldWorld S₄ᵀ이다. S₄는 S에 마지막 동차 행·열을 붙인 행렬이다. OpenCV 카메라 축은 x 오른쪽, y 아래쪽, z 전방이다. 물체의 길이·폭·높이와 물리 코너 번호는 모델 버전에 묶고 세계축 변환과 별도로 관리한다.

1. 고정된 카메라별 해상도·장치 경로·K·왜곡·T_camera_world를 기록한다. 위치를 바꿀 때 calibration_id를 갱신한다.
2. 녹화 CSV의 수신 시각과 모든 카메라에 보이는 점멸로 시간 오프셋을 추정한다. 모호하거나 공통 허용폭을 벗어난 프레임은 유효 그룹에서 제외한다.
3. 각 영상에서 대상 마스크, Canny, LSD와 교점 관측을 추출한다. 왜곡 보정한 K 픽셀을 후단에 전달하고 실제 영상상의 지역 관측 ID는 보존한다.
4. 가까운 초기 자세에서 보이는 모델 특징과 영상 관측을 할당한다. 네 카메라 전체 공동 최적화와 T123/T124/T134/T234를 같은 픽셀에서 평가한다. 3카메라 가설을 각 시점에 투영한 잔차와 유효성을 저장한다.
5. 제외 카메라는 그 가설의 최적화에는 쓰이지 않는다. 그러나 모든 가설이 같은 이전 자세·준비된 대응을 공유하고 두 부분집합은 카메라 둘을 공유한다. 따라서 네 가설의 합의를 네 번의 독립 검증처럼 계산하거나 분산을 4로 나누지 않는다. 시간·보정 오차가 공통이면 모든 후보가 함께 빗나갈 수 있다.
6. 유효하지 않은 측정은 pose=null과 원인을 전달한다. 마지막 유효 자세 기반 예측은 측정과 구분한다. 재획득 평가에서는 마지막 실패 이후 연속으로 유효하고 정확해지는 프레임까지 지연을 기록하고 끝까지 회복하지 못한 경우도 집계한다.

## 실제 하드웨어 검증을 위한 팀 작업

| 담당 작업 | 확보할 산출물 | 현장 판단 기준 |
|---|---|---|
| 마운트·좌표계 | 앞·옆·위·대각 슬롯의 장치 경로, 작업공간과 마운트 사진, 세계 원점과 축, 상자 실측 3축 및 코너 도해 | 정면과 반대편 시야에서 축 방향을 확인. 지그·마운트 변경 이력 보관 |
| 내부·외부 보정 | 실제 녹화 모드의 해상도와 초점, 다양한 거리·기울기의 체커보드, 별도 검증 자세, 칸 길이 | 모든 관측 카메라가 한 세계 프레임에 연결되는지, 보류 영상 재투영 및 물리 거리 점검. 그래프 변환만 합성한 닫힌 경로와 독립 실측 폐루프를 구분 |
| 시간 정렬 | 불규칙 간격의 공통 점멸, AVI/CSV, 시각 보정 보고서, 움직이는 물체의 영상 속도 | 수신 기준과 노출시각 차이 기록. 추정 지터·시간차 × 영상속도가 허용 픽셀 오차 안에 드는지 확인. 세션 간 시계 보정 재사용 금지 |
| 실제 관측 | 같은 시간대 네 시점의 상자, 두 방향 손 접근과 완전 가림 후 재등장, 고정 단일/네 시점 비교용 원본 | 실제 보이는 코너·부분 모서리를 수동 표기. 마스크·교점·물리 ID 오검출을 구분 |
| 초기화·정답 | 독립 지그로 위치·각도를 재현한 정지 구간과 움직임, 허용 대칭 집합, 초기화 개입 기록 | 튜닝과 시험 세션 분리. GT 마커를 추적 입력이 사용하면 marker-assisted 조건으로 보고 |
| 융합·속도 | 같은 관측에 대한 all/average/best/reliable, 한 대 누락·고의 시간 편차·복수 오류, GPU 모드별 측정 | 유효 출력 중 오답 비율, 전체 실패·미복구와 P95 오차를 함께 보고. 촬영→사용 가능한 자세의 지연 P50/P95와 입력·출력 FPS를 실측 |

**열린 결정**은 실제 허용 오차(mm/°), 대칭을 해소할 표식 사용 여부, 초기 자세 제공 방식, 근접 추적 실패 후 전역 재초기화 절차, 네 스트림 처리율과 지연 예산이다. 실제 캘리브레이션·동기화와 독립 자세 기준이 확보될 때까지 합성 수치를 실물 정확도로 전용하지 않는다.
