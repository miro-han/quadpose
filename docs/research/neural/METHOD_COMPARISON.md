# Stage 0 · M01–M12 비교표

학습·추론의 실제 처리 시간이나 효능을 보장하지 않는 상대 비교다. 각 방식의 알고리즘, 가정과 1차 문헌은 별도 문서에서 확인할 수 있다. [방법 조사](METHODOLOGY_SURVEY.md) · [실측 자원](RESOURCE_REPORT.md)

## 입력·비용 계획

비용 표기 `낮음/중간/높음`은 기존 CPU 토큰 실험 대비 상대적인 예상 비용이다. 영상 렌더링·전처리와 학습 비용을 구분했다.
