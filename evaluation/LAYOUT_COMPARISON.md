# 네 번째 카메라의 8개 위치 비교

**실제 상단 마운트 시험은 (−,+,+)와 (−,−,+) 두 위치를 먼저 비교할 근거가 있다.** 앞 위치는 동일 모서리의 관측 범위가 넓고, 뒤 위치는 한 카메라가 빠졌을 때의 자세 제약과 중앙 단면 보드의 공통 관측 각도가 유리하다. 하단 시야와 보정 경로를 확보할 수 있다면 (−,+,−)도 후보로 유지한다. 모델의 기하 가시성, 실제 대응기의 ID 정확도, 보정 및 제작 가능성은 서로 다른 판단 축이다.

### 위치별 결과

세 축 카메라는 +X 측면, −Y 정면, +Z 상단이다. 아래는 한 변 1.30 m, 정중앙을 향하는 렌즈, 실제 꼭짓점 거리 1.126 m를 사용한 **합성** 수치다. 손 접근 14방향을 포함한다. 기하 열은 같은 모서리 **위 같은 위치**의 표본과 정답 형상을 사용한다. 대응·자세 열은 정답 ID를 감춘 별도 추적 실험이다. 이 표에는 바닥·기둥 간섭을 넣지 않았으며 설치 제약 결과는 아래에 별도로 제시한다.

| 대각 카메라 중심 (X,Y,Z) | 모서리 표본 2대+ 가시율 % | 최악 3대 λmin p10 ↑ | 최악 3대 조건수 p90 ↓ | 동일 모서리 ID 쌍 정답률 % | 다른 시점의 올바른 ID 보완율 % | 위치/회전 RMSE (mm/°) | 위치/회전 P95 (mm/°) |
|---|---:|---:|---:|---:|---:|---:|---:|
| (-, -, -) | 93.74 | 593.3 | 31.7 | 68.66 | 83.02 | 0.751 / 0.530 | 1.388 / 0.970 |
| (-, -, +) | 88.52 | 578.3 | 31.4 | 68.33 | 80.00 | 0.786 / 0.537 | 1.762 / 1.095 |
| (-, +, -) | 96.33 | 626.5 | 30.2 | 68.22 | 81.73 | 0.798 / 0.521 | 1.746 / 1.165 |
| (-, +, +) | 91.94 | 572.8 | 32.2 | 68.77 | 77.45 | 0.803 / 0.551 | 1.669 / 1.084 |
| (+, -, -) | 89.89 | 572.0 | 32.1 | 67.99 | 82.35 | 0.788 / 0.549 | 1.408 / 1.236 |
| (+, -, +) | 83.92 | 563.5 | 32.3 | 68.98 | 73.91 | 0.778 / 0.581 | 1.310 / 1.085 |
| (+, +, -) | 93.61 | 595.2 | 31.1 | 68.26 | 80.58 | 0.796 / 0.570 | 1.732 / 1.375 |

거리 비교에서는 축 카메라를 0.65 m에 유지하고 대각 카메라만 같은 반경 0.65 m 또는 실제 꼭짓점 1.126 m로 옮겼다. 모든 시점은 같은 K와 해상도를 썼다. (−,+,−)의 모서리 2대+ 가시율은 각각 96.06%, 96.33%였으나 최악 3대 λmin p10은 888.60에서 626.49로 감소했다. 같은 초점거리에서 더 멀어지면 픽셀 민감도가 달라진다. λ와 조건수의 정확한 스케일은 [정규화와 가시성 계산](layout_geometry/README.md)에 있다.

### 동일 물리 모서리와 가림 보완

- **ID 쌍 정답률**의 분모는 추정기가 서로 다른 카메라의 두 관측을 같은 모델 모서리라고 선언한 횟수다. 두 관측이 실제로 그 ID일 때만 정답이다. 자세 최적화가 일부 이상치를 견뎌 낮은 자세 오차를 얻더라도 모든 대응이 맞았다는 뜻은 아니다.
- **올바른 ID 보완율**은 지정 카메라에서 사라진 모서리 중 다른 카메라가 동일 물리 ID를 맞힌 비율이다. 표에서는 위치에 따라 가려진 모서리 분모도 달라진다. 앞·옆·위 축 카메라만 지정해 분모를 일치시킨 경우, A=(+,−,+)는 62/85개, B=(−,+,−)는 68/85개를 복원했다. B가 같은 손실 85건에서 6건을 더 살렸지만 ID 쌍 정답률은 A 68.98%, B 68.22%였다. 이는 배치 변경만으로 잘못된 대응을 해결하기 어렵다는 결과다.
- 각 손 조건은 세 궤적 × 28프레임이다. 해당 실제 꼭짓점 거리에서 하이브리드 실패율은 8개 모두 0%였다(유효성 거부 또는 오차 20 mm/8° 초과 기준). 한 시점 누락 네 가지도 별도로 실행했다. 대각을 없애면 전 위치가 동일한 축 3대 입력이 되고 하이브리드 결과는 1.023 mm/0.626°로 일치했다. 같은 조건에서 코너 단독은 15.48% 실패했다. [추정 방식·오류·ID 원시 카운트](layout_pose/README.md)
- 바닥을 Z=−0.65 m, 렌즈 여유를 80 mm로 가정하면 실제 하단 꼭짓점은 설치할 수 없다. (+0.56,−0.56) m 기둥(반지름 22 mm)을 추가했을 때 A의 공유 모서리 가시율은 83.92%에서 75.40%로 떨어졌다. 이 치수는 실제 프레임 실측값이 아니다. 가시성 스윕에서 바닥/기둥을 모델링했고, 자세 표의 RMSE/P95는 광학적으로 시야가 확보된 조건의 결과다.
- 보정 담당자는 (−,+,+)에서 단면 체커보드를 모두 동시에 보려 할 때 특히 기울어진 시점이 생긴다는 점을 고려해야 한다. 최종 선택 전에 두 상단 후보에서 **같은 손실 모서리 목록, 실제 ID 정답률, 보류 보드 오차**를 나란히 측정한다. [보드 입사각 계산과 현장 시험](../rig/MOUNT_VALIDATION.md)

원본 생성·측정 코드는 [기하 실험](layout_geometry/)과 [자세 실험](layout_pose/)에 있다. 시험한 궤적·색/무늬 없는 모델·손 구·오류 분포가 제한적이다. 작은 수치 차이를 모든 상자나 실제 손에 대한 배치 순위로 해석하지 않는다.

### 어떤 대응을 같은 물리 모서리라고 보고할 것인가

위치 A·B와 두 상단 후보의 손 가림 336프레임을 다시 평가했다. 자세는 그대로 두고, 투영 모서리에 대한 수직 잔차 RMS ≤2.5 px, 무방향 각도 차이 ≤8°, 유한 구간 겹침 ≥60%를 모두 만족하는 경우에만 동일 ID 주장을 남겼다. 다음 표의 recall 분모는 두 시점에 실제로 검출된 같은 모서리 **쌍**이다. 앞의 기하 가시율과 분모가 다르다. [고정된 게이트·쌍 단위 카운트](edge_identity/README.md)

| 후보 | 초기 ID 쌍 precision / recall | 같은 프레임의 공동 자세로 검증 후 | 해당 카메라를 뺀 자세로 검증 후 |
|---|---:|---:|---:|
| A (+,−,+) | 68.98 / 76.73% | 97.87 / 71.22% | 98.71 / 66.98% |
| B (−,+,−) | 68.22 / 74.30% | 98.15 / 68.25% | 98.83 / 64.02% |
| 상단 (−,+,+) | 68.77 / 75.11% | 97.86 / 69.67% | 98.04 / 65.24% |
| 상단 (−,−,+) | 68.33 / 75.05% | 97.94 / 70.13% | 98.52 / 65.43% |

네 후보의 초기 거짓 쌍 1,936건 중 1,750건에 잡음 선분이 포함됐다. 공동 자세로 검증하면 B에서 고정 축 시점의 가림 보완 68/85건을 유지했고 A에서는 62/85에서 60/85로 줄었다. 해당 카메라를 제외한 검증에서는 각각 56/85와 53/85로 더 감소했다. 이 검증은 **ID 보고의 신뢰성을 개선**하며 자세 업데이트에는 되먹이지 않았다. 실제 손 경계나 인쇄 무늬는 합성 clutter와 다를 수 있으므로 실물에서는 같은 임계값을 별도 평가 영상에 먼저 적용한다.
