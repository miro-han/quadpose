Team 7 현재 상태 및 작업 인계
기준일: 2026-11-24, Asia/Seoul

최종 목표
같은 상자를 여러 RGB 카메라로 관측해 하나의 3D 상자 구조와 위치·회전(6DoF)을 추정한다.
전체 목표를 상자 윗면의 네 꼭짓점 검출로 축소하지 않는다.
사용자 설명에 따라 초기 인계의 평면 판 중심 설계에서 전체 상자로 범위를 확장했다.
직육면체 모델을 선택한다면 8꼭짓점·12모서리를 고려하되 모두 보여야 하는 것은 아니다.
SAM 2는 영상별 대상 영역 선택을 담당한다. obj_id=1은 영상 내 지역 ID이며 공통 물체 ID가 아니다.
수동 박스/클릭은 명시적 초기화다. 완전 자동 인식으로 보고하지 않는다.

검증된 구현과 근거
- capture/: 최대 4슬롯, AVI/타임스탬프 CSV/session.json. 1대 선택 시 영상 1개, 4대는 4개.
  실제 2대에서 각각 49프레임/49 CSV행, 약 10.8 FPS, 큐 누락 0. 합성 4스트림 검증.
  실제 4대 구동은 미검증. 한 버튼 시작은 센서 노출 동기화가 아니다.
  근거: outputs/camera/recorder_checks/hardware_report.json 및 hardware/.
  과거 JSON 내 절대 session 경로는 정리 전 경로일 수 있다. 측정 원본은 유지했다.
- perception/edges/: 긴 원본 530프레임 Canny 출력 재독출, 임계값 시각 비교, LSD 선분 후보 실험.
  근거: outputs/edges/. 정량 정확도를 측정한 것은 아니다.
- perception/segmentation/: 공식 SAM 2.1 Hiera Tiny, CPU, CUDA 확장 후처리 비활성.
  커밋 2b90b9f5ceec907a1c18123530e92e794ad901a4, 모델 해시는 models/sam2_source.json.
  박스·포함/제외 클릭, 첫 마스크 수정, 짧은 구간 추적, PNG/MP4/JSON 저장 구현.
  11~13 원본 프레임 추적: 3프레임 22.887초. 최초 준비 포함 마스크 확인 약 26초 별도.
  GUI 경로는 11~12프레임에서 박스·양/음 클릭·마스크·추적·2프레임 저장 검증.
  근거: outputs/segmentation/20261124_215508_e1cb28 및 20261124_215749_db9b73.
  첫 프레임에서 상자 선택 및 바닥/그림자 제외를 시각 확인. IoU·장기 안정성은 미측정.
  그 외 세션은 상태/출력 개수를 개별 확인. tracking 상태는 완료 실적이 아니다.

변경된 설계 원칙
1. Canny 단독의 손·바닥·그림자 오검출을 줄이기 위해 SAM 2 대상 영역 선택을 추가했다.
2. LSD는 직선 비교 기준이다. 특정 ROI/픽셀 임계값에 맞춘 결과를 범용 해결책으로 삼지 않는다.
3. 마스크는 물체 영역, 에지는 경계 후보다. 가림 경계·표면 무늬와 실제 모서리를 구분해야 한다.
4. 고정 프레임 부재로 보정은 보류. 현재 움직이는 카메라 실험은 2D 분할·추적 평가다.
5. 공개 구현/논문을 적극 활용하고, 자체 연결·융합·평가와 AI 지원 범위를 공개한다.

다음 작업과 완료 기준
P0 지금 가능한 작업
- 손 가림·배경색·그림자·물체색·카메라 움직임 조건을 구분하여 짧은 샘플 자체 촬영.
- 고정 평가 프레임에 대상 마스크와 실제로 보이는 물리적 모서리를 각각 수동 표시.
- 전체 Canny 대 SAM 마스크 내 Canny: 모서리 precision/recall, 허용 거리(px),
  마스크 IoU, 처리 시간, 클릭 수를 평가. 튜닝 자료와 최종 평가 자료를 분리.
- 완전 가림/재등장/장기 추적 실패 및 재초기화 비용 기록. 현재 중간 프레임 교정 UI는 없다.
- 팀원과 관측 형식 합의: camera_id, object_id, source_frame, timestamp,
  좌표계(raw/undistorted), mask/edge 경로, valid, 실패 이유를 포함하도록 확장 예정.
  현재 frames.jsonl에는 프레임 번호, 마스크 면적, 처리 경과 시간만 있다.

P1 고정 프레임 확보 후
- 촬영 설정 고정 → 체커보드 내부 보정·왜곡 추정 → 공통 보드로 외부 보정.
- 실측 보드 칸 크기와 세계 좌표계의 축·단위를 기록. 별도 보드 자세로 검증.
- 수신 시각과 공통 시각 신호로 시간 오차 측정. 우선 2대로 검증 후 4대로 확장.
- 카메라 이동/배치 변경 시 외부 파라미터 재추정. 개별 내부 보정만으로 공통 좌표계가 생기지 않는다.

P2 핵심 구현
- 실측 치수의 직육면체 모델 사용 여부 및 초기 자세 획득 방법 합의.
- 같은 물리점/모서리 대응 또는 모델 재투영 기반 공동 최적화 구현.
- 시점별 가시성·가림·이상치·대칭 처리. 관측 부족 시 실패/무효로 표시.
- 하나의 자세를 여러 영상에 재투영해 검증. 임의 윤곽점 삼각측량이나 2D 에지 단순 중첩 금지.

P3 시스템 효과 입증
- 같은 자료에서 고정 단일 시점 / 최적 단일 시점 / 다중 시점 결합 비교.
- 기준 지그 등 독립 기준으로 위치·회전 오차, 가림 중 유지율, 재획득 시간, FPS 측정.
- 재투영 오차는 영상 적합도다. 실제 3D 오차와 구분하고 대칭으로 불분명한 회전도 반영.
- 마스크만 대 마스크+에지 비교는 융합 구현 후 후보 실험.
- 자체 촬영 조건, 실패 사례, 개인 기여, 공개 코드·논문·AI 지원 범위를 제출 자료에 명시.

미확정 사항
상자 치수/CAD, 정답 자세 측정 방법, 팀원 역할, 제출 일정, 고정 프레임 확보 시점,
실제 4대 USB 대역폭·촬영 속도, GPU 사용 여부. 확정된 사실처럼 보고하지 않는다.
