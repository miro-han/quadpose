# Layout A 축별 가림 보완 확인

## D0 직사각형의 분모

D0의 `occlusion_lost`는 손실 전 기하학적으로 보였던 에지에 대해 영상 직사각형 밖의 가장 긴 연결 구간이 **9 px 미만**일 때만 참이다. 남은 일부 구간의 길이는 가림 이후의 실제 검출 여부와 별개로 평가한다. 기존 독립 D0는 가림 활성 카메라·프레임 12개에서 참 에지 구간 81개를 검사했다. 13개가 짧아졌지만 여전히 9 px 이상이었고, 해당 정의로 손실한 에지는 0개였다. 이 자료에서 가림 보완율은 분모가 없어 계산할 수 없다.

## 별도 광선 교차 진단

기존 D0와 그 학습 데이터는 유지했다. D0의 독립 정상 궤적 두 개를 사용해 정면, 측면, 상단 축을 각각 가리는 별도 조건과 무가림 조건을 구성했다. 손 대용 불투명 구의 반지름은 85 mm다. 해당 축 쪽 상자 지지 평면에 구를 8 mm 떨어뜨려 배치했고, 모든 카메라에서 에지당 17개 광선의 유한 구 교차를 검사했다. Phase III의 기존 광학 가시성·노이즈·부분 관측 생성기를 사용했다. 같은 축·시드의 전후 비교는 동일 자세와 물리 특징마다 고정한 잡음·누락 추출을 공유한다. 무가림 장면은 축 조건마다 재사용했다. 각 축당 24개의 자세와 총 72개의 가림 자세를 계산했다.

분모는 대상 축 카메라에 가림 전 보였으나 가림 후 추정기에 제공할 길이의 선분이 남지 않은 물리 에지의 인스턴스 수다. 분자는 같은 에지 ID를 나머지 카메라 가운데 한 대 이상이 정확히 주장한 수다. GT 대응도 나머지 카메라에 실제 검출 후보가 없는 에지는 복구할 수 없다. 아래 방법에 새 문턱값을 선택하거나 학습시키지 않았다.

| 원래 사용한 방법 | 정면 손실 후 | 측면 손실 후 | 상단 손실 후 | 전체 복구 | 가림 자세 성공 |
| --- | ---: | ---: | ---: | ---: | ---: |
| All | 65 / 127 | 102 / 186 | 30 / 49 | 197 / 362 · 54.42% | 62 / 72 |
| Cross+Verify | 24 / 127 | 41 / 186 | 17 / 49 | 82 / 362 · 22.65% | 29 / 72 |
| Recovery | 59 / 127 | 86 / 186 | 29 / 49 | 174 / 362 · 48.07% | 50 / 72 |
| GT 대응 | 105 / 127 | 140 / 186 | 45 / 49 | 290 / 362 · 80.11% | 72 / 72 |

Cross+Verify의 가림 중 에지 쌍 정확도는 83.67%로 All의 48.42%보다 높았지만, 낮은 측정 밀도 때문에 보완한 에지 수는 더 적었다. Recovery의 가림 위치·회전 RMSE는 9.84 mm·5.24°로 All의 19.24 mm·10.68°보다 낮았고, All은 더 많은 에지와 성공 측정을 보냈다. 같은 손실에 정답 대응을 적용해도 362개 중 72개가 다른 카메라에서 복구되지 않았다. 검출·가시성의 한계에 더해 ID 대응 때문에 생기는 손실이 있다는 근거다. 구는 광학 가림을 대략적으로 모사한다. 사람 손과 설치 환경의 실물 보완율은 동시 촬영 자료로 별도 검증해야 한다.

```powershell
python -B -m evaluation.resource_limits --threads 1 --memory-gib 3 learning.occlusion_sanity --output learning/results/axis_occlusion_replay
```
