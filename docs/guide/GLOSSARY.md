# 용어집

| 용어 | 이 프로젝트에서 쓰는 뜻 |
|---|---|
| Local detection ID / physical ID | 전자는 한 영상 프레임의 선분·교점 식별자, 후자는 물체 모델에 고정된 코너·에지 번호 |
| Occlusion / visibility | 손 등의 외부 가림과 상자 자체 가림. 가시성은 주어진 카메라에서 모델 특징을 기하적으로 볼 수 있는지의 예상 |
| Correspondence / assignment | 특정 픽셀 관측이 어느 물리 특징의 관측인지에 대한 가설, 미할당 가능 |
| Oracle / estimated | 시뮬레이터가 참 ID를 주는 비교 상한 조건과 픽셀·보정·근사 자세로 ID를 추정하는 실제 알고리즘 입력 |
| Extrinsics / intrinsics | 세계→카메라 회전·이동과 렌즈의 초점거리·주점·왜곡 |
| Reprojection residual | 모델을 영상에 투영한 위치와 관측 사이의 차이. 독립 3D 정확도의 대리값으로만 사용 |
| SE(3) / 6DoF | 강체의 3차원 회전과 이동을 합성·역변환할 수 있는 군, 세 회전과 세 이동의 자유도 |
| In-fit / held-out view | 가설 적합에 쓴 시점과 그 가설에서 제외한 시점. 공통 prior 때문에 완전 독립은 아님 |
| Observability / rank | 현재 관측 잔차가 각 자세 변화에 반응하는지, 선형화한 독립 제약 차원의 수 |
| Precision / recall / F1 | 주장 중 정답, 기회 중 회수, 두 비율의 조화평균. 점·에지·카메라 쌍 중 집계 단위를 함께 읽는다 |
| False-valid / lost | 틀린데 유효라고 출력한 사건과 유효 측정을 낼 수 없는 상태. 센서 건강 정책 위반을 셀 때는 별도 명시 |
| Reacquisition | 실패 후 측정 정확도·연속성 조건을 다시 충족하는 사건. 정상 추적에서 다음 프레임을 맞힌 횟수와 구분 |
| Symmetry branch | 기하 투영으로 구분하기 어려운 회전 중 현재 추적 중인 자세 후보 |
