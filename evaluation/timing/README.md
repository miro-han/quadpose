# Phase II 합성 융합 백엔드 CPU 시간

AMD Ryzen 7 6800H, Windows 11, Python 3.12.10, NumPy 2.5.4에서 프레임당 벽시계 시간을 측정했다. OpenBLAS·OpenMP·MKL 환경 변수의 스레드 상한은 1로 설정했다. 공유 데스크톱의 동시 작업·백그라운드 부하는 통제하지 않았다.

| 경로 | 호출 수 | p50 | p95 |
| --- | ---: | ---: | ---: |
| 전체 관측 단일 공동 적합 | 576 | 6.53 ms | 10.46 ms |
| 네 가지 3-of-4 가설, 전체 진단 및 신뢰 뷰 재적합 | 576 | 35.04 ms | 52.68 ms |

두 경로 모두 카메라별 대응을 계산한다. 두 번째 경로는 카메라별 적합, 가능한 3-of-4 가설과 유효성, 전체 관측 공동 적합, 각 뷰의 잔차 및 지지 여부, 진단 패킷, 신뢰 뷰 재적합까지 실행한다. 이 측정에서 중앙값은 두 번째 경로가 5.37배였다. [실행별 상세 시간과 입력 시드](backend_cpu.json)

held-out test split의 8개 조건에서 각각 24프레임을 준비했다. 192프레임에 담긴 네 시점의 코너·선분 검출 결과와 이전 자세를 두 경로에 그대로 입력했다. 조건별 시뮬레이션과 이전 자세 준비를 측정 전에 완료하고 경로당 16프레임으로 워밍업했다. 매 프레임·반복에서 경로 순서를 교대하며 동일 입력을 세 번 평가했다. 영상 디코딩, 카메라 I/O, SAM·LK·이미지 특징 검출, 결과 직렬화·저장은 측정 범위 밖이다. 이 수치는 합성 사전 검출 입력의 CPU 처리 시간이다. 실제 단일 영상 구간의 시간은 [별도 프로파일](../profiling/README.md)에 있고, 실시간 물리 카메라 4대의 종단 지연은 아직 측정하지 않았다.
