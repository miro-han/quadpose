# 현재의 선택이 다음 프레임에 영향을 주는가

선택한 기하 업데이트를 실행하면 그 결과가 다음 프레임의 대응 검색 중심이 된다. 물체와 영상은 고정된 합성 시퀀스로 제공된다. 에이전트가 바꾸는 것은 내부 측정 이력과 누적 미측정 횟수다. 영상 재생 중에도 같은 인터페이스에서 매번 선택한 행동의 자세를 다시 계산할 수 있다.

| 구성 | D0 구현 |
|---|---|
| 상태 | 카메라별 코너·선 개수, 누적 미측정, 마지막 두 측정의 이동량 |
| 행동 | 전체 적합, 교차 시점, 교차 시점+검증, 1–2대 부분 적합, 예측 |
| 행동 마스크 | 검출 수로 판단한 가용 시점. 추론 상태에는 다른 행동의 미계산 결과가 없다 |
| 비교 | 가용 카메라 수 휴리스틱, 한 단계 최적 행동의 Behavior Cloning, 그 가중치에서 시작한 REINFORCE |
| 종료 | 12프레임의 관측 소진. 중간 측정 실패와 상실도 다음 행동에 영향 |

GT 기준 20 mm 및 8° 이내 측정은 +1, 오답 측정은 −2, 예측 −0.45, 상실 −0.9다. 여기에 $\min(2,e_\mathrm{mm}/40+e_\mathrm{deg}/25)$와 동작별 고정 비용 대리값 0–0.18을 뺀다. 측정 거부만 반복하거나 오답을 유효로 보고하기 어렵도록 두 경우를 구분한다. 학습은 보상으로 GT를 읽고 정책의 입력은 관측뿐이다. 실제 벽시계 시간은 별도 지표다. D0는 자세와 비용 보상을 검증했고, 물리 ID 및 가림 복구를 함께 최적화하려면 전이마다 실제 사용 대응을 보상기에 전달해야 한다.

Behavior Cloning의 학습 라벨은 휴리스틱이 방문한 상태에서 동작별 즉시 보상을 비교해 만든다. REINFORCE는 자신의 상태를 방문하고 할인된 반환($\gamma=0.9$)으로 3회 추가 갱신한다. 아래 두 예는 왜 행동에 따라 새 상태가 필요한지 보여준다.

1. 가림으로 교차 시점 추정이 거부되어도 예측을 유지하는 선택과 부분 카메라로 새 측정을 받는 선택의 이후 검색 영역이 다르다.
2. 보정 결함으로 잘못된 위치가 승인되면 다음 프레임의 정합이 더 나빠질 수 있다. 단일 프레임의 잔차 감소만 최적화하면 이 실패가 보상되지 않는다.

### 후속 실험 범위

현재 행동 공간은 이산 전략이다. 연속 SE(3) 증분과 가중치를 직접 출력하려면 Gauss–Newton 및 제한적 다중 시작과 먼저 같은 계산 예산으로 비교한다. 독립 프레임의 가설 랭킹은 지도학습 문제로 분리할 수 있다. 실제 동기 영상에서의 학습 보상은 독립 시점의 투영, 실루엣, 오프라인 teacher 또는 독립 지그의 실측 자세를 비교한다. 이전 결과를 그대로 재생하는 캐시만으로는 행동이 다음 입력에 주는 영향을 평가할 수 없다.
