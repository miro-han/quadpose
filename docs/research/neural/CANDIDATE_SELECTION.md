# D0 결과를 본 뒤 남긴 연구 후보

| 우선 후보 | D0 근거 | 다음 검증에서 달성할 조건 |
|---|---|---|
| 1. 물리 에지 점수 + 기하적 수용 검사 | GT 대응에서 가장 큰 개선 여지. 학습 MLP는 동일 후보 공간에서 F1과 시점 쌍 정확도를 개선 | 학습 자료의 분절·외부 가림을 확대한다. 초기 정보량, 투영 깊이와 작업 영역, 시간 변화와 독립 시점 지지를 검증한 뒤 폐쇄 루프에서 비교한다. 자세 오답과 가림 보완을 둘 다 평가한다. |
| 2. 에지별 신뢰도와 강건 적합 | 대응 점수 가중은 독립 시험에서 일부 잘못된 측정을 줄였으나 회전 및 지연이 늘었다 | 같은 대응에서 단일 선분과 분절을 독립 측정처럼 중복하지 않는 가중치를 비교한다. 에지와 코너 각각의 불확실성 및 calibration으로 리스크–커버리지 평가를 한다. |
| 비학습 기준. 일정 속도 + 제한된 복구 | 개발 자료에서 일정 속도 All이 학습 순차 정책과 같았다. 독립 자료에서는 속도 예측만으로 가속과 방향 전환을 견디기 어려웠다 | 마지막 자세 유지·일정 속도·가속이 있는 필터 및 RecoveryTracker를 비교한다. 고비용 PnP 복구는 호출 조건, 복구까지의 프레임, 최악 비용을 기록한다. |

에지 MLP의 전형적인 실패는 분절 관측과 잘못된 자세 승인이다. 이 모델은 **비교 연구용**이며 Studio 추정기의 제품 기본값 선정은 보류한다. 위 2개 후보는 제한된 기간에 다음 실험의 가치를 검증하기 위한 우선순위다. [효과 크기와 실패](EXPERIMENTAL_RESULTS.md) · [극단값과 가림 분모](FAILURE_ANALYSIS.md)

**확대 보류.** 현 가설 집합에서 oracle regret 개선 폭이 작으므로 M05의 큰 attention·graph 모델은 후보 생성 개선 전에는 우선순위가 낮다. 병진 보정·증류·자기지도는 기존 자세의 조건부 오차를 악화시켰다. RL과 모방은 두 시드에서 기본 All과 같은 동작으로 수렴했고 독립 평가에서 성능 교환이 있었다. RGB 백본과 온라인 적응은 동기 영상·보정·물리 ID 검증이 확보되면 별도 검토한다. [전체 12개 비교](METHOD_COMPARISON.md)

**재현 뒤 확대 조건.** 10,000프레임 안팎의 새 훈련 단계에 들어가려면 에지 유형과 가림별 독립 궤적 수를 늘리고, 서로 다른 학습 시드와 물체 치수·조명·배경·동기 조건에서 신뢰구간을 산출한다. 검토에 사용한 D0 독립 자료는 이후 확장 모델의 최종 시험에서 회귀 자료로 취급한다. 다음 독립 시험은 생성 설정과 시드를 미리 동결한다. 자세 커버리지와 계속 추적한 프레임의 종단 지연, 대칭 등가 자세 오차와 절대 자세 오차도 분리해 측정한다.
