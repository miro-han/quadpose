설계 수정: 보정된 다중 카메라에서 일반 윤곽을 사용하는 자세 추정
2026-11-24 사용자 피드백 반영

최종 목표는 카메라별 상자 관측을 공통 3D 형상/자세로 결합하는 것이다.
수동 ROI와 픽셀 길이 기준에 맞춘 LSD 후보 선별은 기준 실험으로만 유지한다.
특정 영상에 맞춘 선별을 범용 물체 검출/대응의 해법으로 보고하지 않는다.
LSD가 직선 모서리의 비교 기준으로 유효한 것과 시스템 전체를 선분에 한정하는 것은 구분한다.

보정이 제공하는 것
- 카메라별 내부 파라미터와 왜곡 계수.
- 동일한 세계 기준의 카메라별 외부 파라미터. 각 카메라를 따로 내부 보정하는 것만으로 공통 좌표계가 생기지 않는다.
- 알려진 체커보드 칸 크기를 통한 길이 단위.
- 픽셀 광선, 다중 시점 기하 검증, 3D 모델의 영상 투영.
- 보정은 시간 동기화나 대상 식별을 대신하지 않는다.

권장 개발 방향 (아직 구현되지 않은 설계)
1. 실제 해상도/렌즈 설정으로 각 카메라 내부 보정 후 별도 프레임에서 투영 오차와 직선 왜곡 보정 확인.
2. 고정 배치에서 공통 체커보드 기준으로 외부 파라미터 결정 및 다른 보드 자세로 교차 검증.
3. 공통 시점의 영상을 확보하고 수신 시각/점멸 신호로 시간 정렬 검증.
4. 직선/곡선을 표현할 수 있는 에지맵 또는 경계 확률을 유지한다. Canny를 기준으로 학습 기반 방법을 비교한다.
5. 실제 물체 형상과 초기 자세를 이용해 각 카메라에서 보일 윤곽을 예측한다.
6. 영상의 경계 관측과 모델 투영의 거리/방향/영역 일치성을 여러 시점에서 공동 평가하여 하나의 자세를 개선한다.
7. 가림, 이상치, 대칭, 추적 실패와 재초기화를 명시적으로 다룬다.

범위와 전제
- 직육면체 상자가 현재 대상이다. 임의 형상으로 확장하려면 해당 형상의 모델/초기화 또는 별도 재구성이 필요하다.
- 알려진 실측 치수의 모델부터 구현하는 것은 제안이다. 실제 치수 및 보정 자료는 아직 제공되지 않았다.
- 서로 다른 시점의 곡면 실루엣 점은 같은 물리점이 아닐 수 있으므로 임의로 삼각측량하지 않는다.
- 배경/그림자 경계도 여러 시점 기하에 일치할 수 있다. 에피폴라 일치만으로 상자 모서리라고 판정하지 않는다.
- 학습 기반 일반 에지맵 자체는 물체 ID 또는 물리적 모서리 대응을 제공하지 않는다.

우선 참고 자료
OpenCV calib3d (보정, 투영, 다중 시점 기하):
https://docs.opencv.org/4.x/d9/d0c/group__calib3d.html
DeepAC, ICCV 2023 (초기 자세의 CAD 윤곽 투영 + 학습한 경계 분포 + 자세 최적화):
https://zju3dv.github.io/deep_ac/
https://github.com/WangLongZJU/DeepAC
M3T (여러 카메라의 영역/텍스처/깊이 관측을 공통 모델 자세에 결합):
https://github.com/DLR-RM/3DObjectTracking/blob/master/M3T/readme.md
DexiNed (일반 학습 기반 에지 비교 후보):
https://github.com/xavysp/DexiNed
DeepAC는 단일 RGB 비디오 추적이며 다중 카메라 통합은 별도 작업이다.
M3T의 깊이를 이용하는 가림 처리는 RGB-only 구성에서 그대로 사용할 수 없다.

평가
- 같은 검출 관측으로 단일 시점/다중 시점 결과 비교.
- 배경색/물체색/조명/그림자/가림 조건별 실패와 오차 보고.
- 보정용/튜닝용/최종 평가용 자료 분리.
- 재투영 오차는 영상 적합도이며 실제 3D 위치/회전 정확도는 별도 기준으로 평가.
- 최종 시연에서 수동 초기화가 있다면 그 개입 범위를 공개.
