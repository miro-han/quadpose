# Phase IV 실패 분석

추적 실패는 오답을 수용하는 경로와 측정을 거부한 뒤 이전 자세에서 벗어나지 못하는 경로로 나뉜다. 두 경우를 모두 위치·회전 오차, 측정 상태, 물리 ID 수로 확인했다. 합성 프레임에서 최종 오차를 계산할 때는 전 프레임에서 출력한 예측 또는 마지막 유효 측정을 사용했고, 이 값들을 성공한 측정에는 넣지 않았다. [실험 정의](BENCHMARK_PROTOCOL.md)

## 오답 유지와 자기강화

개발 시드 `41011`, 상단 뒤 `x-y+z+`, 복합 결함의 11번 프레임에서 Phase II All이 28.73 mm·58.95°의 오답을 유효로 반환했다. 복합 결함이 해제된 뒤 17번에서도 44.23 mm·63.07°였으며, 주장한 물리 에지 5개 중 1개만 맞았다. 정상 입력이 돌아온 뒤에도 잘못된 이전 자세가 새 대응을 제한하는 도식과 맞는다. 같은 개발 복합 구간에서 교차 정책 세 가지는 14개 활성 프레임을 모두 거부했다. 오답을 측정으로 내보내는 문제는 줄였지만, 같은 방법이 정상 관측 재개를 보장하지는 않는다. [개발 프레임 원자료](results/selection/frames.csv)

랭크 6인 측정도 물리적으로 틀릴 수 있다. 같은 개발 복합 결함에서 `single_legacy`는 12번 프레임에 13.54 mm·69.22°를 반환했다. 그 프레임의 추정 대응에 대한 국소 Jacobian은 랭크 6이었다. 정보 행렬은 현재 대응 주변의 작은 자세 변화가 영상에 드러나는지를 검사하며, 대응이나 해의 물리적 정당성까지 확인하지는 않는다. [대응 절제 원자료](results/assignment/frames.csv)

## 대응을 과도하게 삭제하는 경우

분절 통합은 가려진 실제 에지의 여러 부분을 살릴 수 있다. 가까운 다른 선분까지 한 모델 ID로 결합하면 물리 주장을 오염시킨다. 개발 자료의 분절 조건에서 통합 추가 직후 참 조각 사용량은 늘었지만 엄격한 물리 ID F1은 낮아졌다. 강한 제거 규칙도 에지 조각을 과도하게 지울 수 있다. 한 번 제거한 뒤의 재적합은 유효 관측과 기하가 기준 미만일 때 이전 유효 자세를 보존한다. 번갈아 최적화하는 경로는 반복한 대응 서명을 탐지해 진동하는 후보를 다시 적용하지 않는다. 진동·과삭제 검증은 별도 단위 테스트에 포함했고, 개발 실행에서 실제 종료 사유를 기록했다.
