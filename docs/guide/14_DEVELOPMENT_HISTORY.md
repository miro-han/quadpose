# 설계가 바뀐 이유와 결정의 출처

| 시점 | 해결할 문제와 결정 주체 | 채택 근거·실패·다음 질문 |
|---|---|---|
| 원본 제안서와 초기 인계 | 팀 제안은 실측 가로·세로의 평면 판. 치수 미입력은 확장 아이디어 | 네 점 삼각측량으로 크기를 얻으려면 서로 다른 영상의 같은 물리점을 미리 식별해야 했다. 기본 경로는 실측 모델을 쓰고 크기 자체의 복원은 별도 실험으로 남겼다. 초기 문서에서 이미 두 경로가 구분돼 있다 |
| 상자 추적 인계 | 사용자 설명에 따라 전체 직육면체와 자세로 범위 명확화 | 윗면 사각형 하나로는 옆면과 아래 모서리의 정보를 표현하기 어렵다. Canny 단독의 손·그림자 후보를 줄이기 위해 SAM 마스크를 연결했다. 분할 결과만으로 면 사이 경계의 ID가 생기지는 않았다 |
| Phase I | 연구 후보로 모델 투영·가시성·코너+선 비교 | 코너가 사라져도 부분 선분의 법선 제약이 남았다. 알려진 치수는 같은 표면점이 두 대에 보이지 않아도 각 시점의 서로 다른 특징이 하나의 자세에 기여하게 했다. 합성 데이터에 근거한 선택이다 |
| Phase II | 사용자가 Known Geometry의 모델 기반 대응과 공동 SE(3)를 기본 추정기로 지정 | 전체 공동 적합과 세 카메라 가설을 비교했다. 부분집합이 한 카메라의 체계적 오류를 견디는 경우도 있었으나 전체 방법은 시야가 충분한 특정 조건에서 더 정확했다. 휴리스틱은 일부 오출력을 억제했지만 hold가 길어지며 재획득에 실패했다 |
| Phase III | 팀의 물리 모서리 요구를 기준으로 여덟 꼭짓점과 ID 후검사를 연구 | 기하 가시성과 실제 ID 정답률의 순위가 달랐다. 두 상단 후보 및 조건부 하단 후보를 현장 비교 대상으로 남겼다. 잔차·방향·겹침 후검사는 높은 정밀도와 낮아진 재현율을 보였다. 사용자가 AMD 추가 실험 중단을 지시했다 |
| Phase IV | 사용자 지시로 기하 추정 개선과 독자용 문서에 한정 | 후검사를 재최적화에 연결하고, 반복 할당·제외 시점 검증·퇴화·복구를 시험한다. 성능과 비용이 악화되는 경우까지 기록하고 기본 추정기 전환은 평가 후 결정한다 |

11월 25일 회의의 직접 요구는 사용자가 전달한 대응·가림 보완·공통 자세 추정이다. 3-of-4, 배치별 정보행렬, 신경망 신뢰도는 연구 확장이다. 마커 정책과 최종 장착 위치, 실물 오차 기준은 미확정이다. 원래 자료는 [상자 범위의 인계 기록](../PROJECT_CONTEXT.txt), [설계 제안](../PROPOSED_ARCHITECTURE.md), [II 실패 기록](../../docs/archive/phase2_RESULTS.md), [III 검증](../../docs/archive/phase3_README.md)에서 시점별로 대조할 수 있다.
