# 대응과 자세 추정 후보 비교

**현재 측정한 계산 비용**은 네 시점의 추정 대응 코너+선 추적에서 프레임당 중앙값 16.65 ms(A), 19.77 ms(B), p95 23.99 ms(A), 27.51 ms(B)였다. Ryzen 7 6800H에서 배치별 75프레임 준비 후 225프레임의 모델 투영·대응·자세 갱신을 측정했다. 입력은 합성 특징 좌표이고, 촬영·시간 정렬·RGB 디코딩·SAM·코너와 모서리 검출은 별도 비용이다. 실행 순서와 시스템 부하를 바꾼 반복이 필요하므로 이 수치로 두 배치의 속도 순위를 정하지 않는다. [시간 측정 원본](../experiments/fusion/results/latency.json)

기호 C는 카메라 수(4), N은 시점별 관측 수, M은 모델 특징 수(점 8 또는 선 12), I는 최적화 반복 수, H는 초기 자세 가설 수다. 아래 연산량은 후보를 전수 비교하는 설계의 근사값이다. 실제 지연에는 디코딩·분할·전송·검출이 더해진다. 문헌 번호는 [출처](REFERENCES.md)에 대응한다.

| 방법 | 입력과 수식 | 대응 방식과 기존 코드 연결 |
|---|---|---|
| 점 삼각측량 [1,2] | 보정되고 시각이 맞는 두 시점 이상. 같은 점의 동차좌표 x에 대해 x×PX=0을 쌓아 SVD로 푼다. 양의 깊이와 재투영 잔차 검사 | 마스크 주변 선 교점 또는 수동 코너로 시작. 에피폴라 거리, 접속 모서리 방향, 세 번째 시점으로 후보를 검증. 3개 이상 비공선 모델점과 복원점이 대응하면 강체 정합 가능 |
| 선 삼각측량 [1,3] | 영상선 ℓ이 만드는 세계 평면 Pᵀℓ의 교선이 3D 지지선. 끝점은 관측 구간과 모델 길이로 별도 제한 | LSD 후보 쌍을 방향·선분 범위·접속점·제3시점에서 검사. 두 영상선만으로 보통 어떤 두 역투영 평면도 교선을 만들어 거짓 대응도 맞아 보인다 |
| 모델 에지 [4,5] | 치수·초기 T·가시 모서리. 투영된 선분의 방향, 겹침, 거리로 후보를 줄이고 법선방향 잔차 최소화 | selected_edges의 표본이나 LSD 조각을 각 모델선에 할당. 앞단 출력 후 별도 모듈로 연결 |
| 코너+모서리 [1–5] | 동일 T에서 코너 2D 잔차와 선의 수직 잔차의 강건 가중합 | 교점과 인접 선의 ID 일관성을 검사. 선 교점으로 만든 코너가 같은 픽셀 증거를 중복 사용하므로 공분산 또는 선당 최대 가중치를 적용 |
| ArUco 보조 [2,6] | 마커별 ID·변 길이·상자 기준 부착 변환. 알려진 마커 코너의 공동 재투영 오차 최소화 | OpenCV 검출기의 ID와 코너 순서를 모델 좌표에 직접 연결. 비공면의 여러 면을 함께 관측하면 평면 후보 분리에 유리. 초기화 전용과 매 프레임 보조를 각각 평가 |
| 시간축 optical flow [7] | 연속 영상의 밝기 보존을 가정. 패치 내 Σ(Iₓvₓ+Iᵧvᵧ+Iₜ)² 최소화 | 선택한 코너에 피라미드 LK 적용, 왕복 오차·모델 재투영으로 점검. 기존 모델 ID를 같은 카메라의 다음 프레임으로 전달. 카메라 사이 최초 ID는 기하 또는 마커로 획득 |

| 방법 | 가림·대칭·퇴화 시 동작 | 계산량과 실시간 적용 판단 |
|---|---|---|
| 점 | 같은 코너가 두 시점에 남아야 깊이를 복원. 좁은 광선 교차각, 공선 정합점, 반복 코너에서는 보류 | 후보 O(C²N²), 확정 대응당 소형 SVD. 적은 후보 수에 유리 |
| 선 | 부분 선분을 활용. 거의 같은 역투영 평면, 매우 짧은 선, 반복 평행선은 불안정. 서로 다른 끝점을 같은 점으로 취급하면 편향 | 후보 O(C²N²), 제3시점 검증 비용 추가. 후보 폭 제한이 필요 |
| 모델 에지 | 보이는 조각과 다른 면을 함께 사용. 평행선만 남으면 선 방향 이동이 약하게 제한된다. 등가 자세는 복수 가설로 유지 | 가설당 O(ICMN), 법선 탐색 방식은 표본 수와 탐색 폭에 비례. ROI와 이전 자세가 있으면 프레임 간 추적 후보 |
| 코너+선 | 코너가 가려져도 일부 선 사용, 선을 따라 미끄러지는 자유도는 코너가 보완. 동일 방향 제약 집중·완전 가림·오초기화에서 실패 가능 | 점·선 비용 합과 반복당 소형 6×6 선형계. 밀집 할당 알고리즘을 쓰면 시점별 최대 O(max(M,N)³) 추가 |
| ArUco | 식별 가능한 표식이 절대 방향 제공. 손이 가리거나 표식이 작고 기울면 해독 실패. 단일 정면 평면의 자세 후보는 다른 시점으로 확인 | 영상 픽셀 검사와 사각형 후보별 해독, 소수 코너 최적화. 표식 크기·번짐·속도가 실제 지연과 성공률을 좌우 |
| LK | 한 방향 에지만 있는 패치의 aperture 문제, 무늬 부족, 큰 이동, 밝기 변화에서 이탈. 다른 카메라로 T 갱신 후 코너 재검출. 대칭 재등장에는 별도 초기화 | C개 영상, N점, L단 피라미드, 패치 A픽셀, J회 반복에 O(CNLAJ) 및 피라미드 생성. 제한된 이동의 프레임 간 보조에 적합 |

**선택 기준.** 처음부터 점 또는 선의 다중 시점 대응을 전부 풀려 하면 가림이 심한 특징이 제외된다. 모델 투영 방식은 알고 있는 치수를 이용해 미지 기하를 한 시점당 자세 6변수로 제한하고, 한 카메라에만 보이는 모서리도 활용한다. 초기 자세 오차가 큰 조건에는 지역 탐색이 취약하다. 수동 초기화·마커 초기화·완전 자동 초기화는 필요한 입력과 실패율을 각각 측정한다. 마커를 사용할 경우 부착·변환 측정 비용과 원래 외관의 변화가 있고, markerless 방식은 이 준비가 간단한 대신 절대 축 식별과 재초기화 부담이 커진다.
